# VEDA Day 18 – Region Performance Analysis

## 📊 Project Overview

This project is completed as part of the **VEDA Technology Data Analytics Internship – Day 18 Task**.

The objective of this task is to analyze regional sales and profit performance using **Microsoft Excel and Power BI**. The dashboard provides a clear comparison of sales, profit, and order count across different regions.

## 🎯 Objectives

* Analyze total sales across regions.
* Compare regional profit performance.
* Calculate total order count.
* Identify high-performing regions.
* Create an interactive and professional Power BI dashboard.
* Present insights using charts, KPI cards, and a ranking table.

## 🛠️ Tools & Technologies

* Microsoft Excel
* Microsoft Power BI
* Data Cleaning and Analysis
* Data Visualization
* KPI Cards
* Bar Charts
* Ranking Table

## 📁 Dataset

The dataset contains regional sales and profit information with the following columns:

* Order ID
* Region
* Sales
* Profit

The analysis covers four regions:

* East
* West
* South
* Central

## 📈 Dashboard Features

### 1. KPI Cards

* Total Sales
* Total Profit
* Total Orders

### 2. Sales by Region

A bar chart comparing total sales across the four regions.

### 3. Profit by Region

A bar chart displaying the total profit generated by each region.

### 4. Region Performance Ranking

A table showing regional performance based on total sales and total profit.

## 🔍 Key Results

Based on the dataset used in this project:

| Region    | Total Sales | Total Profit |
| --------- | ----------: | -----------: |
| West      |      11,500 |        1,640 |
| Central   |      10,450 |        1,250 |
| East      |       9,750 |        1,360 |
| South     |       9,280 |        1,260 |
| **Total** |  **40,980** |    **5,510** |

* West recorded the highest total sales.
* West recorded the highest total profit.
* The dashboard includes 20 total orders.
* Regional performance is presented through visual comparisons.
